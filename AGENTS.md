# Sports Store — Main Agent Instructions

You are working on a premium 3D sports equipment and custom sportswear e-commerce frontend.

## Project Goal
Build a responsive React website where customers can browse sports equipment, inspect supported products in interactive 3D, customize sportswear, and send order details to the business through WhatsApp.

## Technology
- React and Vite
- JavaScript
- Tailwind CSS
- Three.js
- React Three Fiber
- Drei
- Lucide React icons where appropriate

## Products
Cricket bats, balls, gloves, pads, helmets, kits, football jerseys, shorts, socks, shoes, badminton rackets, shuttlecocks, nets, basketballs, volleyballs, training equipment and accessories.

## Main Features
- Home page and sports categories
- Search, filtering and sorting
- Product listing and product detail pages
- Interactive 3D viewing for products with available GLB/GLTF models
- 360-degree image galleries or standard image galleries for other products
- Custom jersey name, number, size, color and logo options
- Cart using React state and localStorage
- WhatsApp ordering with a pre-filled message
- Responsive mobile, tablet and desktop layouts

## Project Constraints
- Frontend only in the initial release.
- No backend, database, payment processing or fake authentication.
- Use clearly identified sample product data until real client data is provided.
- Never pretend a WhatsApp message has been sent automatically. The customer must press Send.
- Never claim a product has a real 3D model unless an actual usable model exists.
- Do not invent real client prices, phone numbers, brand assets or product inventory.
- Use configurable placeholders for client information.

## Working Rules
- Read the project brief, project rules and relevant agent instructions before coding.
- Work in small, verifiable phases.
- Do not generate the entire application before the planning and folder structure are approved.
- Keep components reusable and code readable.
- Do not overwrite existing files without inspecting them first.
- Run available checks and report actual results.
- Ask before adding paid services or major dependencies.
- Keep accessibility, performance, security and mobile usability in mind.
