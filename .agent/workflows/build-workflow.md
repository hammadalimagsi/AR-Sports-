# Sports Store Build Workflow

Phase 1 — Discovery:
Inspect repository, available assets and project requirements. Ask about missing client branding and WhatsApp number only when needed.

Phase 2 — Planning:
Define pages, design system, product schema, folder structure, required packages and asset checklist. Update docs/IMPLEMENTATION_PLAN.md. Wait for approval.

Phase 3 — Foundation:
Set up React/Vite and styling only after approval. Verify the development server and production build.

Phase 4 — Storefront:
Build shared components, homepage, categories, product catalog, search, filters and product details.

Phase 5 — Commerce:
Implement customization forms, cart, localStorage and WhatsApp ordering.

Phase 6 — 3D:
Integrate available GLB/GLTF models and fallback image galleries. Optimize loading and mobile controls.

Phase 7 — Quality:
Run available checks, fix verified issues and test all major user journeys.

Phase 8 — Handover:
Document setup commands, configuration values, required client assets, known limitations and deployment steps.

After each phase, summarize changed files, checks performed and the next approval required. Do not skip phases without authorization.
